## Next.js App Router Course - Completed

### Completed the application developed in the official Nextjs course taught by Vercel. Main concepts and skills acquired:
- Styling: Using TailwindCss, taking advantage of the ease this CSS framework provides for styling any web page directly from HTML.
- Optimizations: Applying optimization of links, images, and fonts.
- Routing: Creating nested layouts and pages using file-system routing.
- Data Fetching: Configuring a Postgres database on Vercel, and best practices for fetching and streaming.
- Search and Pagination: Implementing search and pagination using URL search params.
- Mutating Data: Mutating data using React Server Actions, and revalidating the Next.js cache.
- Error Handling: Handling general and 404 not found errors.
- Form Validation and Accessibility: Applying server-side form validation and tips for improving accessibility.
- Authentication: Adding authentication to your application using NextAuth.js and Middleware.
- Metadata: Adding metadata and preparing your application for social sharing.
